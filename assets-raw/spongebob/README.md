# SpongeBob 主题素材工作区

本目录用于海绵宝宝主题的原始素材收集、筛选、裁切、预览与后续构建。

当前已确认的主素材来源：

- GBA 主资源页：
  `https://www.spriters-resource.com/game_boy_advance/spongebobsquarepantsatlantissquarepantis/`

当前目标角色：

- 海绵宝宝
- 派大星
- 珊迪
- 章鱼哥
- 蟹老板
- 痞老板
- 水母

当前用途方向：

- 64x64 像素主题
- 桌宠/待机角色展示
- 多动作角色切换

建议目录约定：

- `downloads/`
  放原始下载 PNG
- `cuts/`
  放后续裁切出的单角色/单动作 PNG
- `preview-64/`
  放压到 64x64 的预览图
- `notes/`
  放补充记录、动作标注、缺漏说明

当前已知注意事项：

- `Atlantis Squarepantis` 这套资源很适合作为主素材池。
- `Patrick` 资源页评论里有人提到可能有缺帧，后续下载后需要肉眼复核。
- 当前先不混入别的主素材池；如后续发现凯伦、背景或特定动作缺失，再单独补来源。
