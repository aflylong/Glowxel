# SpongeBob Duo Hatch Pet

This folder is for a Codex desktop pet inspired by the SpongeBob and Patrick pixel assets.

Goal:
- Create a redrawn, unified, Codex-compatible pet.
- Do not directly reuse the game sprite frames as the final pet.
- Keep SpongeBob-inspired character on the left and Patrick-inspired character on the right.
- Keep consistent pixel style, scale, baseline, and center across all animation rows.

Source references:
- `../cuts/spongebob-frames-refined/`
- `../cuts/patrick-frames-refined/`
- `spongebob-duo-reference-board.png`

Important user requirements:
- Dance must be represented as a real action, not dropped.
- Fail must be represented as a separate slumped reaction.
- Patrick `dance5` must not be used as a dance reference.
- Patrick `dance4` should be kept.
- The two characters should stay together as a left-right duo.
- Sleeping should end on a quiet resting pose and should not look like a looping dance.

Current files:
- `make-reference-board.py`: builds the reference board from selected refined frames.
- `spongebob-duo-reference-board.png`: reference board for image generation.
- `run/`: standard hatch-pet run generated by `prepare_pet_run.py`.

Codex pet state mapping:
- `idle`: calm duo idle.
- `running-right`: drag movement to the right.
- `running-left`: drag movement to the left.
- `waving`: waiting / greeting / needs attention.
- `jumping`: coordinated dance action. This is where the dance series should be expressed in the standard 9-row Codex pet atlas.
- `failed`: explicit fail state.
- `waiting`: thinking / waiting for input.
- `running`: working / processing.
- `review`: success / review / pleased completion.

Known limitation:
- The standard hatch-pet Codex atlas has 9 fixed rows and does not include separate named `dance` or `sleeping` rows. For the standard Codex desktop pet package, `dance` is mapped to `jumping`. Sleeping needs either a custom pet runtime/state extension or must be represented inside `idle`/`waiting` as a quiet resting variant.
