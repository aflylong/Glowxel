# 新增设备模式页面开发指南

> 标准模板：`TerrariaClock.vue`
> 凡是"设备模式预览页"（带 64×64 像素预览 + 配置面板），照本文档操作。

---

## 0. 快速理解：页面外层结构

每个设备模式页面分三层：

```
App.vue
└─ shellName === 'none' (沉浸式无壳)        ← 不要 PublicShell, 不显示官网顶部 NavBar/Footer
   └─ <YourPage>.vue                          ← 模式页面本体
      ├─ status-bar              (状态栏占位)
      ├─ navbar                  (页面自己的导航栏: 返回 + 标题)
      ├─ canvas-section          (64×64 预览 + 发送按钮)
      ├─ content                 (滚动配置区)
      └─ bottom-tabs (可选)      (底部 Tab 切换)
```

**关键点**：
- 模式页**自己写 navbar**（不是 shell 自动给）
- 路径必须被 `App.vue::isDevicePath()` 识别为设备路径，否则会套上 PublicShell（顶部 logo + 底部 Footer 全出来），页面会被压缩
- 高度自适应靠 `flex: 1; min-height: 0`，不需要手动算 `contentHeight`（除非用了 uniapp scroll-view 的 height 属性）

---

## 1. 必做的 6 步

### Step 1: 注册路由（`src/router/index.js`）
```js
{ path: '/your-mode', name: 'YourMode',
  component: () => import('@/views/mobile/YourMode.vue'),
  meta: { shell: 'app' } },
```

### Step 2: 把路径加入沉浸式白名单（`src/App.vue::isDevicePath`）
```js
function isDevicePath(p) {
  return p.startsWith('/device-') ||
    p.startsWith('/your-') ||         // ← 加这一行
    // ... 其他既有
    p === '/clock' || ...;
}
```
**漏掉这一步页面会被套 PublicShell，顶部出现"光格像素工坊 PIXEL STUDIO"，底部 Footer 全显示，预览区被压缩、滚不到底。**

### Step 3: 把模式加入 DeviceControl 主页列表（`src/views/mobile/DeviceControl.vue`）
在 `modeList` 数组里加：
```js
{
  key: "your_mode",
  name: "你的模式",
  icon: "navigation",
  variant: "orange",
  type: "mode",
  bucket: "secondary",
},
```
然后在点击处理里加跳转：
```js
} else if (mode === "your_mode") {
  this.openYourMode();
}
```
方法：
```js
openYourMode() {
  uni.navigateTo({ url: "/pages/your-mode/your-mode" });
},
```
（`uni.navigateTo` 会自动映射到 `/your-mode` Vue Router 路径）

### Step 4: PC 控制台也加（`src/components/device/DeviceControlConsole.vue`）
找 `modes` 数组加：
```js
{ key: "your_mode", name: "你的模式", icon: "navigation",
  variantClass: "device-home__mode-card--orange",
  action: "open", to: "/your-mode" },
```

### Step 5: 创建页面文件（`src/views/mobile/YourMode.vue`）
**直接照抄下面的模板**：

```vue
<template>
  <div class="your-page glx-page-shell">
    <div class="status-bar" :style="{ height: statusBarHeight + 'px' }"></div>

    <div class="navbar glx-topbar glx-page-shell__fixed">
      <div class="nav-left" @click="handleBack">
        <Icon name="direction-left" :size="32" color="var(--nb-ink)" />
      </div>
      <span class="nav-title glx-topbar__title">你的模式</span>
      <div class="nav-right"></div>
    </div>

    <div class="canvas-section">
      <div class="preview-canvas-container" :style="previewCanvasBoxStyle">
        <PixelPreviewBoard
          v-if="previewCanvasReady"
          :width="64"
          :height="64"
          :pixels="previewPixels"
          :refresh-token="previewTick"
          :zoom="previewZoom"
          :offset-x="previewOffset.x"
          :offset-y="previewOffset.y"
          :grid-visible="true"
          :is-dark-mode="true"
        />
      </div>
      <div class="preview-caption glx-preview-panel">
        <div class="preview-caption-info glx-preview-panel__info">
          <span class="preview-caption-title">预览效果</span>
        </div>
        <div class="preview-actions">
          <div class="action-btn-sm primary glx-primary-action" @click="sendToDevice">
            <Icon name="link" :size="36" color="#000000" />
            <span>发送</span>
          </div>
        </div>
      </div>
    </div>

    <div data-scroll-view scroll-y class="content glx-scroll-region glx-page-shell__content">
      <div class="content-wrapper glx-scroll-stack">
        <!-- 你的配置面板 -->
        <div class="settings-card">
          <!-- ... -->
        </div>
      </div>
    </div>

    <Toast ref="toastRef" />
  </div>

<script>
import uniLifecycleAdapter from '@/mixins/uniLifecycleAdapter.js';
import statusBarMixin from '@/mixins/statusBar.js';
import Icon from '@/components/uni/Icon.vue';
import Toast from '@/components/uni/Toast.vue';
import PixelPreviewBoard from '@/components/uni/PixelPreviewBoard.vue';

export default {
  name: 'YourMode',
  mixins: [uniLifecycleAdapter, statusBarMixin],
  components: { Icon, Toast, PixelPreviewBoard },
  data() {
    return {
      previewPixels: new Map(),
      previewTick: 0,
      previewCanvasReady: false,
      previewZoom: 4,
      previewOffset: { x: 16, y: 16 },
      previewContainerSize: { width: 320, height: 320 },
    };
  },
  computed: {
    previewCanvasBoxStyle() {
      return { height: `${this.previewContainerSize.height}px` };
    },
  },
  mounted() {
    this.$nextTick(() => {
      this.previewCanvasReady = true;
      this.initPreviewCanvas();
      // 启动你的渲染循环
    });
  },
  methods: {
    handleBack() {
      try { this.$router.back(); } catch (e) { window.history.back(); }
    },
    initPreviewCanvas() {
      this.$nextTick(() => {
        setTimeout(() => {
          const query = uni.createSelectorQuery().in(this);
          query.select('.preview-canvas-container').boundingClientRect((data) => {
            if (data && data.width > 0) {
              this.previewContainerSize = { width: data.width, height: data.width };
              const fitZoom = Math.max(2, Math.floor((data.width * 0.96) / 64));
              this.previewZoom = fitZoom;
              this.previewOffset = {
                x: (data.width - 64 * fitZoom) / 2,
                y: (data.width - 64 * fitZoom) / 2,
              };
            }
          }).exec();
        }, 80);
      });
    },
    sendToDevice() {
      // 发送到设备的逻辑
    },
  },
};
</script>
```

### Step 6: 验证 4 个点
1. 顶部 **没有** "光格像素工坊 PIXEL STUDIO" 大 logo（说明 isDevicePath 加对了）
2. 顶部 **有** 自己的 navbar（"← 你的模式"）
3. 滚动条能滚到底，最后一项完全可见
4. 发送按钮的 link 图标是黑色的（`#000000`）

## 2. CSS 变量速查表

| 变量 | 用途 |
|---|---|
| `--bg-primary` | 顶层页面背景（少用） |
| `--bg-secondary` | `.your-page` 整体底色、卡片背景 |
| `--bg-tertiary` | `.preview-caption` 标题栏、`.content` 滚动区背景 |
| `--bg-elevated` | 底部 tab 栏 |
| `--nb-ink` | 主黑线条/边框/icon |
| `--nb-yellow` | 主操作色（发送按钮、active 项） |
| `--text-primary` | 标题、主文字 |
| `--text-secondary` | 次要文字 |
| `--layout-bottom-offset` | iOS 底部安全区适配 |

**禁止**新增 CSS 变量。

## 3. PixelPreviewBoard 标准 props

```vue
<PixelPreviewBoard
  :width="64"                        ← 板载分辨率, 固定
  :height="64"                       ← 固定
  :pixels="previewPixels"            ← Map<"x,y", "#hex">
  :refresh-token="previewTick"       ← 计数器, ++ 强制刷新
  :zoom="previewZoom"                ← initPreviewCanvas 自动算
  :offset-x="previewOffset.x"        ← 居中偏移
  :offset-y="previewOffset.y"
  :grid-visible="true"               ← 是否显示像素网格
  :is-dark-mode="true"               ← 暗色模式
/>
```

## 4. 常见错误清单

| 错误现象 | 原因 | 修复 |
|---|---|---|
| 顶部出现"光格像素工坊"大 logo | `isDevicePath` 没加路径 | App.vue::isDevicePath 加 `p.startsWith('/your-')` |
| 滚动到一半滚不动 | 用了 `height: calc()` 算错 | 改用 `flex: 1; min-height: 0; overflow-y: auto` |
| 底部最后一项被裁切 | content-wrapper 没留底部 padding | 改 `padding: 0 0 calc(56rpx + var(--layout-bottom-offset, 0px))` |
| 预览区被拉伸 | canvas CSS 大小和 width/height 属性不匹配 | canvas 的 `width="64" height="64"`，CSS 也用 64×64，靠 `image-rendering: pixelated` + 父容器整数倍放大 |
| 发送按钮 icon 颜色不一致 | 各页面写法不统一 | 统一用 `color="#000000"` |
| 顶部 navbar 重复 | 既写了自己的 navbar，又被 PublicShell 包了 | 检查 isDevicePath；删除多余 navbar |

---

## 5. 不要做的事

- ❌ 不要给非时钟页加 `clockPreviewMixin`（会污染命名空间）
- ❌ 不要新增 CSS 变量
- ❌ 不要把 `<PixelPreviewBoard>` 换成原生 `<canvas>`，除非确实需要 60fps
- ❌ 不要用 `a || b` fallback 写法（项目规则）
- ❌ 不要在 sub-agent 调研前自己改东西
- ❌ 不要把模式页设计成"在 PublicShell 里嵌套"——所有设备模式必须沉浸式无壳
